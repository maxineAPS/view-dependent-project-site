# Constructing Printable Surfaces with View-Dependent Appearance (SIGGRAPH 2023)

Project page: https://maxineaps.github.io/view-dependent-project-site/

Interactive walkthrough of the paper (`index.html`) and a design tool (`app.html`). Static site, no build step.
The optimizer of the code release (Python and PyTorch) was ported to JavaScript so that it runs in the browser;
`py/` holds the repository files the page quotes from.
